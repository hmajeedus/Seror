# Seror Aesthetics

Marketing site for an esthetician and cosmetic studio — landing page, services, booking CTA, and an About page featuring founder **Seror**.

## Stack

- React + TypeScript + Vite
- Tailwind CSS v4
- React Router

## Development

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (typically `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Pages

- `/` — Cinematic landing: full-bleed hero, concern matcher, image-rich services, outcomes bars, gallery, reviews, FAQ, split booking with success state
- `/about` — Founder Seror (portrait, credentials, quote), timeline, philosophy, CTA

## PoC notes

- Imagery loads from Unsplash (swap for brand photography).
- Booking form simulates success — connect Calendly, Square, or Formspree for production.
- Contact details are placeholders.
